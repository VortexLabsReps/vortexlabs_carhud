# Third-party components · Componentes de terceros

| Component | Used for | Licence |
|---|---|---|
| **Lucide**: paths of the fuel, engine, nitro, cruise, arrow and close icons (bundled in `html/app.js`) | Icons | ISC License, © Lucide Contributors (below) |

Everything else is VortexLabs' own work:
- the VortexLabs logo (`html/vortexlabs-logo.png`),
- the seatbelt and headlight pictograms,
- the sounds in `html/sounds/*.wav`, synthesised without third-party samples,
- the Lua, JavaScript and CSS code.

The interface uses the fonts installed with Windows (Bahnschrift, Segoe UI, Cascadia Mono or Consolas). No font files are bundled.

*Todo lo demás es obra propia de VortexLabs: el logotipo, los pictogramas del cinturón y del faro, los sonidos (sintetizados sin muestras de terceros) y el código Lua, JavaScript y CSS. La interfaz usa las fuentes instaladas con Windows; no incluye archivos de fuentes. Los iconos Lucide se distribuyen con la licencia ISC.*
